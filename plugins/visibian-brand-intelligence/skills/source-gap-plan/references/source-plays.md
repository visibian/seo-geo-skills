# What it takes to appear on each kind of source

| Kind of source | Examples | What earns a place |
|---|---|---|
| Listings and profiles | Directories, marketplaces, app stores, Google Business Profile, comparison databases | Claim the listing, complete it, keep facts and categories current, link to the site |
| Review sites | Category review platforms, app store reviews, local reviews | Ask real customers to review, make it easy, answer reviews; never buy, gate or write them |
| Editorial and comparison articles | "Best X for Y" roundups, trade press, comparison blogs | Offer the editor something worth citing: original data, a clear product brief, access for a fair test; ask for factual corrections where an article is wrong |
| Communities and forums | Reddit, industry forums, Q&A sites | Answer real questions as the brand, openly, where the rules allow it; help first, link only when it answers the question |
| Reference sources | Wikipedia, Wikidata, standards bodies, industry associations | Follow each one's rules on notability and conflicts of interest; add facts with references; let independent editors write articles |
| Video and podcasts | YouTube reviews, industry podcasts | Offer demos and experts for interviews; publish your own explainers with transcripts |
| The brand's own pages | Product, pricing, comparison, guides, docs | Answer the buyer's question plainly, with evidence and dates; keep facts consistent |

Measure each play by whether the page now mentions the brand accurately, not by a promised change in AI answers.
