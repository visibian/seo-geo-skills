# Visibian skills

This extension adds Visibian's skills for SEO and AI search (GEO and AEO). They load when a request matches them. The free skills work on any website; the skills that read Visibian data need the Visibian connector, which the `connect-visibian` skill sets up.

Rules for every skill:

- Report what was observed or what a named source says, with its date. Never invent a score, a ranking or a statistic.
- Never simulate another assistant's answer or present one answer as a measurement.
- Report Visibian data exactly as the tools return it, with the date range.
- Never print or store a token.
