# Security

To report a security problem in these plugins or skills, write to support@visibian.com with "Security" in the subject. Please do not open a public issue for it.

The skills contain instructions and Python scripts that use only the standard library. The scripts send requests only to the pages and files a user points them at, and to Google's APIs (PageSpeed Insights, Chrome UX Report, Search Console) with the user's own key or token. The Visibian connector is read-only and is reached only at https://mcp.visibian.com/.
